

# 🎮 Game Analytics Dashboard

An interactive Game Analytics Dashboard built using Python, Pandas, and Streamlit. This project analyzes game data to uncover insights about genres, ratings, platforms, and overall game performance through visualizations and key metrics.

## 📌 Project Overview

The purpose of this project is to perform data analysis on a game dataset and present meaningful insights through an interactive dashboard.

The dashboard helps users:
- Explore game data
- Analyze genre distribution
- Compare game ratings
- View platform-wise statistics
- Identify trends and patterns

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Streamlit
- Matplotlib
- Seaborn

## 🚀 Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project folder:

```bash
cd Game_Analytics_Dashboard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run app.py
```
